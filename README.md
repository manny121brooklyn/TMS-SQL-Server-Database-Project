\# Transportation Management System (TMS) SQL Server Database Project



\## Project Overview

A SQL Server database project designed for a logistics and transportation company to manage fleet operations, drivers, shipments, customers, billing, maintenance, and compliance.



\## Technologies Used



\- Microsoft SQL Server

\- SQL Server Management Studio (SSMS)

\- T-SQL

\- Database Design

\- Constraints

\- Triggers

\- Stored Procedures

\- Data Validation



\## Database Modules



\### Fleet Management

\- Trucks

\- Trailers

\- Assignments

\- Ownership tracking



\### Operations

\- Customers

\- Shipments

\- Dispatches

\- Rates



\### Financial

\- Invoices

\- Payments

\- Expenses

\- Fuel Costs



\### Maintenance

\- Repairs

\- Maintenance History



\### Compliance

\- Driver Documents

\- Drug Tests

\- Incidents

\- Tickets
